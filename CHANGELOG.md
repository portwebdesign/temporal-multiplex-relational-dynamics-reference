# Changelog

## v0.5.1 — 2026-11-15

- Added the declared local stationary-branch continuation study for six
  separately varied synthetic coefficients, its protocol, 11 retained local
  fold records, tests, and all saved outputs.
- Added the declared regulatory-program cost--time map, its protocol, all
  eight program trajectories across nine costs and 101 observation times,
  tests, and all saved outputs.
- Added a standalone public renderer for the stationary-branch and cost--time
  figures, plus pinned tested NumPy, SciPy, and Matplotlib dependencies.
- Preserved all v0.5.0 source, configuration, test, and synthetic-output
  records unchanged.

All values remain synthetic and uncalibrated. The continuation is a local
one-parameter numerical analysis and the program map is a finite-grid
comparison; neither establishes human thresholds, an optimal intervention, or
person-level prediction.
